# NodeBridge v0.46.2 Beta

本版用于 Windows x64 内网部署验证，重点完善安装、远程 MCP 管理和多节点部署说明。

## 安装包

- 文件：`NodeBridge-beta-v0.46.2-20260907.exe`
- 平台：Windows x64
- SHA256：`620208E9B275EAFA1DA2C856C1BFE774F996A5A00FD402DAC6304A7EC3D6BA14`
- 包含：NodeBridge、SyncAgent、Erlang/OTP、RabbitMQ、Java Runtime、Canal、WinSW
- 不包含：MySQL。中心服务器和每台边缘节点需要单独安装并配置 MySQL。

## 主要变化

- MCP 提供 26 个 NodeBridge 管理工具，可经 SSH stdio 从 Windows 或 Mac 调试电脑管理目标节点。
- 新增一台中心服务器、N 台边缘节点的部署、RabbitMQ 账号隔离、公钥授权和撤权手册。
- 修复 32 位 NSIS/PowerShell 环境漏查 x64 Erlang 和 RabbitMQ 的问题。
- 安装组件进程保留真实退出码，并在安装后继续探测组件，诊断日志保存在 `%ProgramData%\NodeBridgeInstallerLogs`。
- 安装器为实际安装账户授予 `%ProgramData%\NodeBridge` 的继承 `Modify` 权限，修复原子保存 `config.yaml` 时 `rename ... Access is denied`。
- UI 与 MCP 对外版本统一为 `0.46.2`。

## 安全边界

- MCP 默认关闭，不开放 HTTP 端口。
- 正式环境使用普通模式；`-lab-full-access` 仅用于隔离测试网络的首次配置和验收。
- 每位调试人员、每台调试电脑使用独立 SSH 私钥；只把公钥加入目标 Windows。
- NodeBridge 凭据使用 Windows DPAPI，加密配置不能直接复制到另一台电脑或另一个 Windows 账户。

## 验证范围

- Go 单元测试、`go vet`、`golangci-lint`。
- 前端测试、TypeScript/Wails contract 和生产构建。
- MCP initialize、26 工具列表、读写配置与规则 smoke。
- NSIS 32/64 位安装器回归、离线资产 hash、最终安装包解包和 preflight。

真实生产数据库切换和所有边缘节点并发运行仍需按[内网部署与远程管理手册](../lan-deployment-guide.md)逐台验收。
