## Checkpoints

- `Clean-Windows-Installed`: created after Windows Server installation and PowerShell Direct verification.

## Install Plan

1. Install Windows Server in `NodeBridge-V034-InstallerLab-G1`.
2. Select a Desktop Experience image.
3. Set the local `Administrator` password to the value listed in `docs/test-credentials.md`.
4. After the first successful desktop login, create checkpoint `Clean-Windows-Installed`.
5. Copy NodeBridge installer test assets into the VM.
6. Create checkpoint `Before-NodeBridge-Installer`.
7. Run installer apply inside the VM only.
8. Verify Erlang, RabbitMQ, Canal, NodeBridge files, services, ports, and managed boundaries inside the VM.
9. Create checkpoint `After-Installer-Apply`.
10. Run uninstall or repair checks inside the VM.
11. Create checkpoint `After-Uninstall-Verify` if cleanup passes.

## Safety Rules

- Host Erlang, RabbitMQ, and Canal must remain untouched.
- Use only `NodeBridge-V034-Isolated` for this lab unless network access is explicitly needed and approved.
- Keep installer assets outside source-controlled paths when they are large binaries.
- Record any failed installer step with the exact command, exit code, and VM checkpoint name.
