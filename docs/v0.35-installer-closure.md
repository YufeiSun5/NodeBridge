# V0.35 Installer Closure Beta

V0.35 upgrades the headless installer test bundle from preflight-only to install / verify / uninstall beta.

## Scope

- Package `SyncAgent.exe` for Windows Server 2022 Core.
- Validate offline asset catalog and SHA256.
- Execute Erlang installer when `-ExecuteInstall` is used.
- Execute RabbitMQ installer when `-ExecuteInstall` is used.
- Register and start `NodeBridgeRabbitMQ`.
- Bootstrap NodeBridge RabbitMQ vhosts, users, permissions, and topology.
- Extract Canal package to `%ProgramData%\NodeBridge\canal`.
- Register and start `NodeBridgeCanal` only when a WinSW wrapper is provided.
- Remove NodeBridge managed vhosts/users/services with `-Uninstall`.

## Commands

Build bundle:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\package-headless-installer-test.ps1
```

Default safe preflight:

```powershell
.\scripts\headless-installer-test.ps1
```

Real install inside VM:

```powershell
.\scripts\headless-installer-test.ps1 -ExecuteInstall
```

Require Canal service wrapper:

```powershell
.\scripts\headless-installer-test.ps1 -ExecuteInstall -RequireCanalService
```

Verify installed resources:

```powershell
.\scripts\headless-installer-test.ps1 -VerifyOnly
```

Uninstall NodeBridge resources:

```powershell
.\scripts\headless-installer-test.ps1 -Uninstall
```

## Current Limits

- Erlang/OTP program uninstall is not performed.
- RabbitMQ Server program uninstall is not performed; only `NodeBridgeRabbitMQ` service and NodeBridge logical resources are removed.
- Canal service requires a WinSW wrapper copied into `packages/`.
- MySQL and real CDC are not part of this installer beta test.
