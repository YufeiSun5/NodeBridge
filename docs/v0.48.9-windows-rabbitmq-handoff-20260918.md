owner：backend-ai，跨 test-ai 仅隔离验证与封包。现场未部署、未执行迁移、未启动同步。

## 修复

修复 `nodebridge_ensure_server_edge_user` 在 Windows 上返回 `The system cannot find the path specified` / exit 255。旧 runner 使用面向普通可执行程序的参数引用方式调用 `.bat`，权限正则中的 `|`、括号被 cmd 解释。新版显式构造批处理命令，逐参数引用，关闭 AutoRun 与初始延迟展开，保留实际失败输出和退出码。对于双引号、百分号、感叹号、换行或 NUL，明确拒绝以防批处理展开改变参数；普通带空格、括号的安装路径可用。

不改变权限正则、MCP API、规则或迁移策略；无需新增 SQL，沿用 0.48.8 的 011 系统迁移。新包同时包含此前双向计划重建能力。

## 使用

安装 `build/NodeBridge-beta-v0.48.9-20260918.exe`，退出旧管理程序和 MCP 进程后重新连接。主站升级后重新调用“配置边缘账号”（实际 node.id，例如 edge-001），确认 configured 并读回权限。建议两端统一升级；配置保留。安装本身不执行业务迁移。

后续迁移继续遵循 [迁移说明](rebaseline-migration.md)：105 为权威源，备份目标后重建，108 独有行不会自动合并到活动表。当前现场同步仍未验收。
