# V0.36 Installer Real Closure

V0.36 moves the headless installer bundle from safe preflight to a real VM install / verify / idempotency / uninstall loop.

## Bundle

Build:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\package-headless-installer-test.ps1
```

Output:

```text
build/NodeBridge-headless-installer-test-v0.36.0.zip
```

## Real Package Prep

Inside the extracted bundle, put files under `packages/`:

```text
packages/otp_win64.exe
packages/rabbitmq-server.exe
packages/canal.deployer-1.1.8.tar.gz
packages/WinSW-x64.exe          # optional, required only for Canal service
```

Generate the real catalog:

```powershell
.\scripts\prepare-installer-assets-catalog.ps1
```

The script writes:

```text
deploy/windows/nodebridge-assets.json
```

Do not commit real installer packages or the machine-specific generated catalog.

## VM Commands

Run only inside the isolated WinServer2022 Core VM from an elevated PowerShell session.

Default preflight:

```powershell
.\scripts\headless-installer-test.ps1
```

Real install:

```powershell
.\scripts\headless-installer-test.ps1 -ExecuteInstall
```

Verify:

```powershell
.\scripts\headless-installer-test.ps1 -VerifyOnly
```

Idempotency:

```powershell
.\scripts\headless-installer-test.ps1 -ExecuteInstall
.\scripts\headless-installer-test.ps1 -VerifyOnly
```

Uninstall:

```powershell
.\scripts\headless-installer-test.ps1 -Uninstall
.\scripts\headless-installer-test.ps1 -Uninstall
.\scripts\headless-installer-test.ps1 -VerifyOnly
```

The final `-VerifyOnly` should fail because `NodeBridgeRabbitMQ` has been removed. For V0.37 and later, it may also fail because NodeBridge vhosts/users have been removed while an existing `RabbitMQ` service is preserved.

## Current Boundary

- V0.36 does not uninstall global Erlang/OTP.
- V0.36 does not uninstall the RabbitMQ Server program directory.
- V0.36 removes only NodeBridge-managed services, vhosts, users, manifest, and optional NodeBridge data directory.
- V0.37 must not delete unknown or customer-owned `RabbitMQ` services. It may reuse an existing broker and remove only NodeBridge vhosts/users during uninstall.
- Docker is not part of this test.
