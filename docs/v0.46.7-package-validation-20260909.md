## 修复内容

1. Server Canal 批量 PENDING/SUCCESS 日志；仅连续 append_only INSERT 使用批量发布，CRUD/DDL 保留逐事件确认屏障。
2. publisher 64 条确认窗口，错误/取消后处理旧确认，阻止不确定 channel 被错误复用；失败 Canal 批次回滚重试。
3. append_only 批内按 event_id 去重，每条投递仍保留结果位置；compact 不跨重复旧更新合并，严格业务 INSERT 继续保留约束错误。
4. 打包默认版本统一为 0.46.7；headless preflight 显式接收版本。两个打包脚本改为命名参数 splatting，避免 `-NoBuild` 被绑定为资产目录，`NoZip/RefreshConfig` 被错误按位置传递。

没有本轮新增的 Wails DTO、前端页面、SyncEvent 协议或数据库迁移。优化证据和失败分析见 `server-cdc-dispatch-optimization-20260909.md`。
