## 本包内容

- 严格 INSERT，不把主键冲突静默改成覆盖；缺行 UPDATE 明确失败，同值 UPDATE 正常处理。
- 明确 HARD/SOFT 删除；旧规则未指定时保持 SOFT。主键完整性、映射碰撞、可见主键变化及真实目标 PK 校验。
- 按已保存规则选择本机源/目标库表预检结构及非执行式 DML 权限；启用前检查。预检不证明远端结构新鲜、存量一致或触发器/外键副作用已核验。
- 规则保存 CAS、saved/active revision；事件运行重试状态与 ACK FAILED 分开显示；禁用规则的入队消息不再静默 ACK。
- 按规则+事件的受控队列隔离 plan/apply/audit，持久副本先于原消息 ACK；有界取样可能改变顺序，不能当作业务应用成功。
- 修复 SERVER_TO_EDGE 明确目标库被本机默认库覆盖的问题；保留源库表列的事件语义。
- 修复 Canal 二进制高位字节被 UTF-8 重编码，新增带标签 base64 行值，经队列/JSON/回放后恢复原字节绑定 SQL；NULL 与空二进制分开。
- MCP 无损数值及可信进程时间脱敏修复；普通启用模式开放39工具/5资源，不新增角色、申请或审批。
- 按用户决定彻底撤回未发布 VPN/HTTP/token、机器范围凭据、SYSTEM远程任务/防火墙与专用 UI，沿用已有 SSH + stdio。不由安装器部署 SSH/VPN。
- 沿用0.46.15半自动组件选择，默认复用已有组件；复用升级不重设连接、配置、规则或密码。

## 安装前必看

1. 备份各机配置/规则，停止同步并显式退出管理UI。工作区副本须在原管理入口停止，安装器不会按进程名清理任意副本。
2. 核对旧规则。启用的 `BIDIRECTIONAL`、`SERVER_WIN`、`LAST_WRITE_WIN` 本版明确拒绝，因为其冲突语义尚未实现。不要擅自改业务方向以绕过校验。
3. 中心和关联边缘同包升级，再检查连接、规则及预检结果后启动。新二进制标签不支持与旧节点混跑；已错写的旧数据和旧消息不会自动纠正。
4. 已有Docker/原生组件选择默认“复用现有组件”；不重复安装组件。MySQL不由本包安装，组件选择页不自动验证连接。
5. SSH使用配置所属Windows账户及已有公钥，不跨账户/机器复制DPAPI密文；私钥仅留控制电脑。MCP不新增监听端口。
