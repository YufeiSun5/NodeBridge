# 0.48.3 小屏规则管理界面

## 使用方式

规则页改为左侧搜索列表、右侧单条详情，避免每条规则的四个表单同时铺满窗口。可按规则 ID、源/目标数据库和表名查找；选择其他规则后未保存草稿仍保留。

详情分为“表映射、路由、主键、列策略”四页签。只读状态也使用相同布局；窄于 760px 时列表变为规则选择框。保存/新增/刷新位于顶部，滚动时保存操作保持可达，修改后显示未保存提示。保存期间禁用编辑，避免异步保存覆盖新输入。

字段说明由“字段说明”按钮展开，长说明可换行；删除等风险提示始终显示。预检、已保存/运行版本及首次对齐位于“预检与首次对齐”展开区，原有运行/恢复及状态轮询保留。一次保存仍保存全部规则，并沿用鉴权、CAS 冲突检查和后端校验。
