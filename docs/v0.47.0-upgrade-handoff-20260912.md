## 安装前

1. 中心和关联边缘使用同一0.47.0包；先备份数据库、连接配置、规则及相邻pair/status文件。
2. 在原入口停止两端同步，显式鉴权退出旧UI；关闭窗口仅隐藏到托盘。不要由本次测试进程代替业务操作员停止工作区副本。
3. 由用户运行安装器，默认复用现有组件并保留配置；不安装MySQL，不自动Docker探测，不修改SSH服务或账户。
4. DPAPI密文不可跨机器/账户搬运。按指南保存禁用双向草稿，两端分别明确执行对齐；双方完成后由用户启动Agent。

本轮没有在业务安装目录执行安装器，也没有复跑上一版的两次完整覆盖安装或SSH连接验收；不能将上一版证据当成本包新增验收。测试容器及浏览器服务已清理，其他容器未动。

## 保留事项

- LWW使用源binlog秒级时间，同秒确定性排序；源时钟回退可能使后发指令落败。本轮夹具显式递增时间仅稳定测试，不是业务时钟修复。尚无任意业务时间字段或严格删除指令时间来源支持。
- 不支持多Edge同表编排、大表断点续传、在线全量、SERVER_WIN。历史版本/墓碑与归档队列清理未自动化。
- FB-107本轮限定的双节点首次全量/双向功能已交付；该项历史数据整改及较早`6f813a`收敛超时缺现场问题仍open，不因短测未复现而关闭。
