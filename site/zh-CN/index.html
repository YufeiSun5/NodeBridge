03 / CONNECT

管理多个节点

每个 Windows 节点独立配置一个客户端条目。本机走 stdio，Windows 或 Mac 可通过 SSH 使用配置所属账户远程连接。

接入你的 MCP 客户端

先从本机连接开始。

在 NodeBridge 中保存完整配置并开启 MCP。使用配置所属的 Windows 账户运行客户端，按客户端要求调整 command 和 args 的配置格式。

查看 MCP 工具文档 ↗远程 SSH 接入指南 ↗
常见客户端配置格式JSON
{
  "mcpServers": {
    "nodebridge": {
      "command": "C:\\Program Files\\NodeBridge\\app\\SyncAgent.exe",
      "args": [
        "mcp-stdio",
        "-config",
        "C:\\ProgramData\\NodeBridge\\config.yaml"
      ]
    }
  }
}

明确的操作边界。 MCP 不监听 HTTP 端口，不提供任意 Shell 或原始 SQL。保留配置校验、输出脱敏和写操作审计。首次对齐需所有参与端停止 Agent、显式确认并持续轮询；running 不代表完成。
