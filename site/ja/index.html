01 / INSPECT

何が起きたかを把握

概要、スキーマ、キュー深度、有限のログとイベント記録を確認。診断アーカイブを出力して調査できます。

02 / MANAGE

調査から対応へ

設定の検証・保存、ルール管理、Agent 制御、失敗イベントの再試行。データ変更は構造化計画と明示確認で行います。

03 / CONNECT

複数ノードを管理

Windows ノードごとにクライアント項目を追加。ローカル stdio または Windows・Mac から SSH で設定所有アカウントに接続します。

MCP クライアントを接続

まずはローカル接続から。

NodeBridge で完全な設定を保存し MCP を有効化。設定所有者の Windows アカウントで実行し、command と args をクライアントの形式に合わせます。

MCP ツール資料 ↗SSH 接続ガイド ↗
一般的なクライアント設定JSON
{
  "mcpServers": {
    "nodebridge": {
      "command": "C:\\Program Files\\NodeBridge\\app\\SyncAgent.exe",
      "args": [
        "mcp-stdio",
        "-config",
        "C:\\ProgramData\\NodeBridge\\config.yaml"
      ]
    }
  }
}

明確な操作範囲。 MCP HTTP リスナー、任意 Shell、生 SQL は提供しません。設定検証、マスキング、書き込み監査を維持。初期整合には全参加端の Agent 停止、明示確認とポーリングが必要です。running は完了ではありません。
